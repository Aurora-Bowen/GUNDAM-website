# GUNDAM Website

🌐 **Website:** [https://aurora-bowen.github.io/GUNDAM-website/](https://aurora-bowen.github.io/GUNDAM-website/)

📦 **GUNDAM Source Repository:** [gundam-organization/gundam](https://github.com/gundam-organization/gundam)

This repository contains the source files for the new GUNDAM website
and user documentation.

## Current development phase

The current phase focuses on establishing the website framework.

The main goals are:

- reproduce the proposed GUNDAM website style;
- implement the main website navigation;
- create the top-level page structure;
- simplify access to the GUNDAM source repository;
- connect the website with GitHub Issues and Discussions;
- prepare the framework for future documentation migration.


## Repository structure

The website is built using Jekyll and GitHub Pages.

The repository contains:

- Markdown files for page content;
- Jekyll layouts and reusable includes;
- navigation configuration;
- SCSS styles;
- JavaScript for responsive navigation;
- static website assets.


## Documentation migration

The existing documentation currently stored under `gundam/docs`
will not be migrated immediately.

The initial website framework will first be reviewed before deciding
how the existing documentation maps into the new structure.
