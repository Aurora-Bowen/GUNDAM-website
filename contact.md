# Contact Us

<p class="lead">
Use the resources below to ask questions, report problems,
or contribute to GUNDAM.
</p>


## Ask a question

General questions about using GUNDAM can be discussed through
[GUNDAM Discussions](https://github.com/gundam-organization/gundam/discussions).


## Report a problem

Software bugs, unexpected behavior, and documentation problems
can be reported through
[GUNDAM Issues](https://github.com/gundam-organization/gundam/issues).


## Source code

The GUNDAM source code is available from the
[GUNDAM GitHub repository](https://github.com/gundam-organization/gundam).


## Contribute

Contribution instructions will be added after the website and
documentation workflow have been finalized.
