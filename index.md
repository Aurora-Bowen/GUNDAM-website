# GUNDAM

<p class="lead">
Generalized Unified Neutrino Data Analysis Methods
</p>

GUNDAM is a configurable framework for statistical analysis,
event reweighting, likelihood construction, and model fitting.

This website brings together the main resources for learning,
installing, using, and contributing to GUNDAM.
