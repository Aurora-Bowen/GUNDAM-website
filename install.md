# How to Install GUNDAM

<p class="lead">
This section provides the main installation workflow for GUNDAM.
</p>


## Installation workflow

The general installation procedure will follow these steps:

1. Check the software requirements.
2. Clone the GUNDAM source repository.
3. Configure the build environment.
4. Build GUNDAM.
5. Set up the runtime environment.
6. Verify the installation.


## Platform-specific installation

Platform-specific instructions will eventually be provided for
supported computing environments, including:

- macOS
- LXPLUS
- DUNE GPVM
- CC-IN2P3 / Lyon
- NNHome
- Seawulf
- Cedar
- other supported platforms


## Source repository

The source code required for installation is maintained in the
[GUNDAM GitHub repository](https://github.com/gundam-organization/gundam).
