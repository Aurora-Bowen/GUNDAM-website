# Tutorials

<p class="lead">
Step-by-step examples for learning how to configure and run GUNDAM.
</p>


## Tutorial workflow

The tutorial section will guide users through a typical analysis workflow:

1. Prepare the input files.
2. Create a basic GUNDAM configuration.
3. Define datasets, samples, and parameters.
4. Configure event reweighting.
5. Run `gundamFitter`.
6. Inspect the fit output.
7. Compare and validate the results.


## Beginner tutorials

The first tutorials will focus on small examples that demonstrate
the basic GUNDAM workflow before introducing experiment-specific
configurations.


## Advanced examples

Additional tutorials may later include:

- normalization fits;
- covariance fits;
- parameter scans;
- MCMC studies;
- experiment-specific configurations.
